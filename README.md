# ATLAS 3.3 — Aurora Liquid Glass

مشروع مستقل جاهز للنشر على GitHub Pages. الواجهة الجديدة تستخدم خلفية Aurora متحركة، زجاجًا شفافًا متعدد الطبقات، ألوانًا منفصلة للإحصائيات والأقسام، وأيقونات SVG بأسلوب Lucide منفصلة عن الأزرار والكروت.

## الملفات
- `index.html` — التطبيق كاملًا (HTML/CSS/JavaScript).
- `.nojekyll` — إعداد GitHub Pages.

## النشر
1. أنشئ مستودع GitHub جديدًا باسم `ATLAS-3.3`.
2. ارفع الملفات في جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واحفظ.

## Gemini
من إعدادات الموقع عيّن كلمة مرور قفل واجهة إعدادات الذكاء الاصطناعي، ثم أدخل Gemini API Key واحتفظ بالنموذج `gemini-2.5-flash` واضغط اختبار الاتصال. يجب توفير مفتاح صالح من Google AI Studio.

## ملاحظات مهمة
- لم يتم اختبار الاتصال بمفتاح API خاص بالمستخدم.
- مفتاح Gemini يُستخدم من المتصفح ويُخزن محليًا؛ قفل الواجهة ليس حماية أمنية للمفتاح. لا تستخدم هذا الأسلوب لموقع عام أو لمفتاح حساس؛ استخدم Backend/Worker لإخفائه.
- بيانات الكتب والخطة محفوظة محليًا في المتصفح، ويمكن تصدير نسخة احتياطية.
- حد رفع PDF الظاهر في الواجهة لا يضمن قبول Google لكل ملف؛ قد توجد حدود إضافية للحجم والصفحات والحصة.
